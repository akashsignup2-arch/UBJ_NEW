# UBJ Houseboats - Premium Website Redesign

A completely scratch-built, ultra-premium frontend for UBJ Houseboats. This project is a digital identity and lead-generation site, focusing on emotional storytelling, cinematic visuals, and driving WhatsApp inquiries.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Features
- Cinematic scroll-linked hero section
- Immersive "Day on the Houseboat" timeline
- Premium masonry gallery with lightbox
- Highly optimized, SEO-first architecture with Schema Markup
- Sticky WhatsApp lead-generation CTA
- Fully responsive, mobile-first design

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment
This application is optimized for deployment on Vercel.
1. Push this repository to GitHub.
2. Import the project in Vercel.
3. Deploy. (Next.js config is automatically handled).
